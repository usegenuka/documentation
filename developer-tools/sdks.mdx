## Installation

<Tabs>
  <Tab title="npm">
    ```bash
    npm i genuka-api
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add genuka-api
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add genuka-api
    ```
  </Tab>
  <Tab title="bun">
    ```bash
    bun add genuka-api
    ```
  </Tab>
  <Tab title="PHP">
    ```bash
    composer require genuka/genuka-php
    ```
  </Tab>
</Tabs>
